# Evidências de testes

Guarde aqui trechos de log, screenshots e notas de cada execução.

## Regras

- **Não** colocar dumps SQL com dados sensíveis
- **Não** colocar senhas, HexID ou `Database.ini` com Password real
- Preferir trechos curtos de `java0.log` (login/game)
- Nomear pastas por data: `YYYYMMDD-ciclo1/`, `YYYYMMDD-baseline-logs/`

## Estrutura sugerida

```
evidencias/
├── README.md
├── baseline-logs/     # snapshot antes do Ciclo 1
└── YYYYMMDD-ciclo1/   # evidências do Ciclo 1
```
